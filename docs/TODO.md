## 容量锁、APOD 公平与错误可见性：待改

- **容量锁收尾**：核对回执恢复、全局槽位与供应商令牌的一致性，逐请求对账及可审计收尾；结果/计费未知时不自动释放或重复付费调用。
- **APOD 公平调度**：避免新闻/翻译任务争抢造成饥饿，验证有界退避、去重和跨任务公平；媒体就绪不代表中文翻译成功。
- **错误可见性**：区分本地准入、接口容量、冷却、数据库故障和上游 429，保留 APOD 子步骤脱敏异常及真实回执关联；不要只显示 `translation_unavailable` 或整轮成功。
- 采用合成慢响应、低并发、429、未知结果及多实例场景验证；没有证据不宣称已修复。参考[容量与积压说明](../KNOWN-ISSUES.md#模型服务容量与处理积压)。

## arXiv 采集调度：待修复

现状：六小时冷却有两套计时基准——普通重试按上次开始时间、HTTP 429 按保存暂停时间——而调度只在北京时间 09/15/21 固定钟点触发；重试早到几秒即整档跳过，没有到期补发。2026-10-13 实际发生：09:02 失败后，15:00 的触发早于门槛约 17 秒被跳过，下一次实际尝试落到 21 点。

已确认的目标逻辑：

- 当天第一次采集成功且有论文入库 → 当天不再采集。
- 失败，或成功但没有新论文数据 → 自该次任务结束起 6 小时后再次采集。
- 上游 429 要求更长等待 → 按更晚时间执行，绝不提前。
- 部分成功（正常论文已入库、仅个别版本异常）→ 当天结束，异常按现有机制单独处理。

实现要点：取消固定采集钟点与队列自动重试，只保留业务六小时重试；维护单一持久化的"下次可采集时间"，由后台定期到期检查触发（检查本身不请求 arXiv）；保留每日最多两次重试、跨日冷却、人工暂停、防重复与租约互斥；重启不丢失等待时间。实现并通过审查前，不改生产调度。

## 观测指南

本快照已保留首页天象日历卡片中的指南入口及只读指南页，采用人工筛选、显式文章 ID 名单。本发行包不附带任何指南文章 ID，名单为空，页面显示空状态；文章不多时继续人工维护即可，不要求自动分类。最终发布状态以发行版本为准。

可选社区贡献（不阻塞首版发布）：
- 按专用标签聚合公开指南，支持分页及原始发布时间排序。
- 对明确的固定观测栏目采用来源＋栏目规则自动打标，避免宽泛关键词误收新闻。
- 提供人工补标、撤标和纠错入口；公开撤回文章不展示。

暂不增加额外 AI 分类调用。不承诺以上功能已实现，贡献者须先核对现有标签读写及公开 API 契约。

## 其他后续方向

以下为可选社区贡献，不表示已实现，也不取代首版必须完成的安全与验收工作。具体限制见[已知问题](../KNOWN-ISSUES.md)。

- **信息源扩展**：评估新的官方 RSS/Atom 或已有通用列表适配；记录未接入、已配置、已验证等不同状态，分别核对采集、AI 输入、全文与图片权限。
- **错误记录扩展**：私有状态页、低频通知、定时只读查错、历史错误导入与复杂卡住诊断；查错不得触发业务重跑、额外模型调用或自动释放未知请求安全锁。
- **论文版本与公告策略**：有界处理旧投稿的新修订、交叉公告及缺失版本；保持官方日期、版本证据、幂等与付费边界，不补造历史。
- **错误与回执历史**：更清晰地关联真实 attempt 和校验观察，明确旧记录的粒度缺口。
- **阅读体验**：公式的桌面/手机渲染、重复说明精简；保留科学原文与必要来源、日期及 AI 提示。
- **媒体自然链路核验**：针对新文章核对图片提取、身份、许可、署名、审核和代理加载；人工补图不能替代自动链路验收。

优先小范围贡献和可复现证据；尚未完成的隐私修复、平台权限及迁移兼容验收不是可跳过的可选 TODO。


## 🌙 社区彩蛋：天文工作者健康与野外观测生存指南

**愿你的观测只被云打断，不被蚊子、胃痛和远光灯打断。**

夜间观测、久坐处理数据和野外工作，除了需要好设备，也需要照顾好使用设备的人。欢迎同行分享经验，并邀请医疗、营养及户外安全专业人士贡献有可靠来源的建议：

- **身体维护**：不规律作息下的睡眠与恢复、咖啡因和光照管理、便携餐食与补水、久坐活动，以及设备搬运的体能准备。
- **野外安全**：按地区准备防虫蜱、蛇及野生动物措施；保暖、防风雨与雷电，通信、结伴、天气监测和撤离计划。
- **暗夜保卫战**：提前协调场地照明，合理使用红光，减少车灯和突发照明干扰；遮光不遮通道，不影响必要安全照明。
- **知道何时停止**：疲劳驾驶、恶劣天气和身体不适优先处理，观测可以改期；持续失眠、明显日间嗜睡或反复胃肠不适，应寻求专业帮助。

这是可选的社区文档方向，不是首版开发承诺，也不要求新增AI功能。经验与专业建议应明确区分；健康及应急内容需注明来源、适用地区和条件，不提供个体化诊疗、激素干预或通用冒险处方。现场安全与当地官方指引优先于暗适应和观测效果。
