# 诺贝尔奖专题页

[中文](NOBEL.md) | [English](NOBEL.en.md)

`/nobel` 是本站的一个专题页。它以 resource route 返回一份自带样式的 HTML 文档，保留文档自身的搜索、筛选、详情弹窗与主题切换；桌面侧栏、手机「更多」页和首页主内容区顶部都提供入口。

## 本发行包的内容边界

本包**不附带**任何第三方奖项文字、图片、标志或转载稿。随源码发布的 `apps/web/app/features/nobel/demo.html` 与 `nobel-demo-banner.png` 都是本项目自行编写的**合成演示**素材，页面上明确标注「合成演示 · 非真实获奖信息」，不含任何真实奖项、得主、引文或官方链接，也不伪造真实得奖者。

## 换成你自己的内容

`apps/web/app/routes/nobel.ts` 只做两件事：把 `{{NOBEL_PENDING_SUMMARY}}` 换成按揭晓日历派生的计数，并把文档里的图片占位路径换成打包后的资源地址。接入自有内容时：

1. 用你有权发布、并已记录来源与许可的文档替换 `features/nobel/demo.html`；
2. 保留 `.calrow` 行与 `待揭晓` 标记，`pendingSummary()` 与测试据此派生计数；日历行结构改变时同步更新 `apps/web/tests/nobel.test.ts`；
3. 替换或删除配图。第三方图片、机构标志与商标不随代码许可使用。

## 口径

计数表示**揭晓状态**（是否已公布），不是官方事实核验，也不按时间推算、不访问外部奖项站点。内容人工维护，不承诺自动更新。
