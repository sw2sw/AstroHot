# 内容版权与来源核查方法

## 核查范围声明

AstroHot提供内容采集、AI辅助分析与阅读工具，不提供所有来源的统一版权授权。**项目没有对所有信息源完成版权分析，也没有逐张核查所有图片。**来源配置、抓取成功、RSS可访问或模型判断，均不代表已经取得复制、AI处理、公开展示或再分发许可。

代码的开源许可仅适用于相应代码，不自动覆盖新闻、论文、摘要、图片、字体、日历数据、标识与商标。公开发行包不应夹带无再分发依据的真实语料、图片或运行档案。具体核查状态与功能必须以最终发布版本及对应证据为准。

## 设计考虑与控制方法

- **分开判断用途**：访问原站、私有存储、提供给模型、公开摘要、公开全文、图片展示与再次分发是不同用途，不能用一种许可推断全部用途。
- **明确材料范围**：区分完整正文、官方摘要、公开片段和仅元数据；AI导读说明使用的材料范围，不把摘要写成已经阅读全文的结论。
- **RSS 与摘要**：RSS 订阅可访问不等于获准转载。自行撰写的简短事实摘要与复制 feed 摘要不同，后者仍须核查许可；翻译、署名和链接不能替代授权。
- **保留出处**：保留来源、原文链接及必要作者/图片署名。署名和链接不能代替许可，也不能自动使使用合法。
- **限制公开出口**：全文公开与再分发分别由`site_fulltext`、`syndicate_fulltext`等配置控制；图片由来源配置与公开读层控制。杂志摘要导读方案关闭全文公开/再分发及`config.cardImageAllowed`，无需为了最终不展示的图片额外逐张调用AI判断版权。
- **不混淆采集和展示权限**：`site_fulltext=false`不是禁止原网页读取的开关，`cardImageAllowed=false`也不能单独证明图片未进入私有存储或AI输入。部署者应沿实际采集、模型输入与公开DTO路径检查各自用途和限制。
- **访问受限即保守处理**：遵守来源条款、频率限制与robots规则，不绕过登录、订阅墙、验证码或反爬措施；无法取得授权的用途保持关闭，无法确认的权利状态标记为未知，不自动判为允许。
- **模型不是授权机构**：AI可辅助提取条款和识别风险，不能代替真实许可文本、权利人授权或专业法律判断。AI重新撰写也不当然消除原材料的权利风险。

## 开发者自行核查与分享

欢迎部署者和其他开发者根据自身使用场景，核查需要启用的来源并分享结果；不要求为了使用工具先完成全互联网版权普查。核查可按来源进行，若许可排除第三方图片、部分栏目或特定内容，再按文章/图片细化。

建议分享记录至少包括：

1. 来源名称、官方域名、feed或栏目范围。
2. 官方条款/许可/授权证据链接，核查日期、适用版本及相关原文引用（仅限允许分享的必要片段）。
3. 分项用途结论：访问、私有存储、AI输入、公开摘要、全文、图片及再分发；每项标注允许、限制、禁止或未知及依据。
4. 署名、回链、非商业、地域、期限、第三方排除等条件。
5. 核查者、核查方法、未覆盖范围和推荐配置；区分官方证据、法律意见与个人推断。

分享时不要附私人订阅凭据、不可公开的授权函、付费全文、真实用户数据或未经许可的图片。可先提交公开证据和脱敏摘要，通过Issue/PR等最终项目协作渠道讨论。

**社区分享不自动成为项目的授权承诺，也不自动修改默认配置。**维护者应核对证据、适用范围及条款更新后决定是否采纳；发现条款变更、权利争议或证据失效时，暂停对应用途并更新记录。具体使用的合规责任仍由部署者结合所在地法律与实际用途判断。

## 声明状态与参考依据

本文为版权与使用说明准备稿。对于尚未核实的权利归属、素材使用范围、截图/品牌使用及出版许可边界，标注为**“暂定／待核实”**；解释性建议标注为**“参考说明，非法律意见”**，并尽可能附官方条款、适用范围和核查日期。未知不等于允许，暂定说明不构成授权，也不能覆盖已有许可或法律规定。

- **已确认的上游义务**：保留适用的MIT版权及许可声明。不得以“暂定”降低上游许可义务，也不额外声称MIT代码的出版使用一律需要维护者批准。
- **第三方内容**：文章、图片等相关权利归各自作者或其他权利人；具体权利人及用途许可未核实的，标为待核实。本项目不提供统一授权。
- **项目原创内容、截图及品牌**：权利范围与个别许可政策尚待确认，不自动适用CC BY或其他未批准的内容许可。普通介绍、客观链接及法律允许的引用不一概要求事先批准；超出既有许可或法律允许范围的使用，应向相应权利人确认。
- **成果引用建议（参考）**：注明AstroHot、正式仓库地址、版本或commit、访问日期、实际使用的部分和修改情况；保留涉及的上游归属，不暗示官方背书。推荐的完整引用格式与许可证本身的强制义务应分开说明。

只有核实权利人、适用对象和许可条件后，才能将对应“待核实”条目更新为明确许可。后续声明不能当然撤回已经有效授予的许可。公开发行前须复核本说明及素材范围；版权声明不是已完成法律审查的证明。
