# 错误记录首版范围

[中文](ERROR-RECORDING.md) | [English](ERROR-RECORDING.en.md)

状态：已有隔离开发候选，尚待最终验收与发行集成。本页仅说明计划范围；正式源码发布时按实际验收更新。

## 计划实现
复用任务运行、缺失/拒绝批次、模型回执与重试记录；补充一个幂等错误事件入口。RSS解析/入库失败后的来源响应保存在私有持久存储中，不因业务事务回滚而丢失；只读查询输出脱敏统计及内部关联。

## 不实现
不自动修复、请求来源、重跑模型、解除暂停或释放未知回执；不提供公开错误API、不新增网页/通知或高频巡检。

## 隐私与证据
只保存必要的来源失败响应，模型原答复复用已有回执关联，不在新事件里复制。认证信息、查询参数、数据库连接串及私人路径不进入摘要。真实证据不能放公开Issue或Git仓库。

## 口径
区分部分成功与整轮失败、人工暂停、429退避、容量等待和未知请求。科学筛选/版权审核的有效拒绝不是系统故障。计数代表真实错误观察，不随重复查阅增加；记录器自身失败应标检查不完整，不报告零错。

最终CLI命令及字段以实际交付为准，当前不提供虚构可运行命令。
