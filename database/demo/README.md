# 合成演示数据

[中文](README.md) | [English](README.en.md)

本目录提供一组**本项目自行编写**的最小合成数据，用于在空白数据库上渲染出有内容的首页、主题页与影像卡，方便截图、演示和人工界面检查。它**不是**真实采集结果。

## 内容

- `imagery/<sha256>`：本项目自制的几何占位图（由 SVG 绘制的同心环，不是任何真实天文照片，也不是 NASA APOD 影像）。文件名是它内容的 SHA256，与影像路由要求的媒体键一致。
- 数据行由 [`scripts/demo-showcase.ts`](../../scripts/demo-showcase.ts) 写入：一个停用的演示来源、5 条标注「【演示数据】」的新闻条目（分属不同分类与主题标签），以及 1 条影像档案记录（中英说明均为自写，`translation_status`/`media_status` 均为 `ready`，模拟「图片与翻译都已就绪」的正常业务状态）。

## 用法

```sh
# 迁移并初始化来源之后
node --env-file=.env scripts/demo-showcase.ts
# 想看首页的影像卡，另需 IMAGERY_ENABLED=true 后重启 api/web

# 清除：只删除本目录写入的那些行，不触碰其他数据
node --env-file=.env scripts/demo-showcase.ts --clean
```

两个方向都可以重复执行。脚本不调用模型、不访问任何上游来源，也不写回执。

## 边界

- 所有标题、摘要与说明都带「演示」标记，且不引用任何真实机构、任务、论文、报道或图像。
- 影像卡展示的图片是自制占位图；`sourceUrl` 指向保留域 `example.invalid`，不指向真实来源。
- 影像记录的 `source` 沿用档案表的取值 `nasa-apod`：表约束与写入校验只接受该值，换成别的取值会违反应用自身的不变量。因此档案页的来源标签会显示 `NASA APOD`，但该行的标题（「非 NASA 影像」）、说明、署名与图片本身都明确标注为自制合成演示，`mediaType` 为 `image` 所以不会出现「原视频」提示。不要把它当成真实影像或译文。
- 不要把这些行当作真实内容发布；正式部署请用你自己的采集与审核流程填充数据。
