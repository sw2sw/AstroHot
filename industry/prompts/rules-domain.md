1. 天文中英对照与歧义默认值：以下词在中文有非天文歧义，**一律按天文含义翻译**：
   - exoplanet = 系外行星（绝不译"外星/系行星"）
   - black hole = 黑洞
   - neutron star = 中子星
   - pulsar = 脉冲星
   - supernova = 超新星
   - gravitational wave = 引力波
   - dark matter = 暗物质（不译"隐形物质"）
   - early universe = 早期宇宙
   - corona = 日冕（太阳大气外层，不译"电晕"）
   - flare = 耀斑（太阳/恒星表面爆发现象，不译"闪焰"）
   - asteroid = 小行星（不译"小行星带"混淆）
   - comet = 彗星
   - survey = 巡天（系统性天区普查，gurvey/survey，不译"巡猎"）
   - redshift = 红移（z 值）
   - magnitude = 星等（天体亮度，不译"幅度"/"震级"）
   - luminosity = 光度（不译"亮度"混同恒星）
   - transit = 凌（行星过境遮光，不译"过境"）
   - drift = 飞掠/漂移
   - density = 密度
   - signal = 信号（探测信号，非"化学信号"）
   - μ/persistent 等后缀单位原样

2. 以下正式编号 / 命名 / 名目 铭牌 **一律保留英文原文**，中文备注用中文，不翻译不加中文扩写：
   - 天体/星表编号（举例 + 通用规则）：NGC / HD / M / HIP / TYC / Gliese / Barnard's / Kepler- / TESS / TOI / HD 189733 b 等
     **规则**：任何正式星表编号、天体命名一字不改（含数字字母后缀 如 NGC 1672、M87、HD 29400），绝不"翻译性扩写"
   - 望远镜/仪器名（举例 + 通用规则）：JWST（詹姆斯·韦布空间望远镜）/ Hubble / HST / ALMA（阿塔卡马） / VLA / EVN / Chandra / XMM-Newton / Fermi / TESS / Vera C. Rubin / Subaru / 等
     **规则**：官方英文名或官方命名保留英文
   - 任务/项目名：WMAP / Planck / SDSS / DES / Euclid / Aristoteles / Xuntian / 巡天等，保留英文
   - 技术缩写（举例 + 通用规则）：CMB（宇宙微波背景）/ FRB（快速射电暴）/ GRB（伽玛暴）/ KN / GW / SNR（超新星遗迹）/ AGN（活动星系核）/ QSO / SMBH / EHT / IGM / IM等
     **规则**：2-5 字母全大写缩写，默认按天文含义保留英文
   - 单位/坐标：RA（赤经）/ Dec（赤纬）/ J2000 / § / pc（秒差距）/ Mpc / ly（光年）/ Au / eV / keV / σ / z 等原样保留

4. 歧义处理（天文特有，注意区分）：
   - mean = 平均 或 均值（统计平均）—— 不译"中间值"
   - magnitude = 星等（亮度）—— 不译"幅度"；magnitude 指"星等"（视觉亮度）
   - survey = 巡天（而非"调查/勘察"）
   - emission / absorption ……（发射/吸收）
   - "space telescope" = 空间望远镜（不加"宇宙"二字）
   - 距离单位：ly / pc / kpc / Mpc 原样

   - 反引号代码 `code` 不翻译
   - URL 原样
   - 数字+单位：z=1.5 / 12,000 K / ×10⁻³ / 0.3 Mpc 原样
   - 金额、比例、区间保留原文阿拉伯数字和单位，不要把数值改写成中文数量词
   - 坐标、RA/Dec、弧秒、角秒 等原样
