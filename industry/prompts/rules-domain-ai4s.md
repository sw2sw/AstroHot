【AI4S 领域翻译规则 — 本栏目是「AI 赋能科学」（AI for Science），覆盖生命科学、材料、地球科学、物理、数学、化学等多学科，不是 100% 天文，严格遵守】

1. 按材料自身的学科翻译，不预设天文含义。术语取它在本文语境里的意思；同一词在不同学科含义不同，**绝不强行按天文翻译**：
   - corona：太阳物理语境译「日冕」；材料/放电语境译「电晕」；病毒学语境译「冠状病毒」；语境不明时保留原文或按本文学科，不默认日冕。
   - survey：天文语境译「巡天」；社科/统计语境译「调查」；测绘语境译「测量」；按本文学科取义。
   - magnitude：天文语境译「星等」；地震学译「震级」；数学/物理译「量级/幅值」；按本文学科取义。
   - transit：天文语境译「凌/凌日」；交通/运输语境译「 transit/通行」；按本文学科取义。
   - flare：太阳/恒星语境译「耀斑」；工业/燃烧语境译「火炬/ flare」；按本文学科取义。
   - signal、density、mean、emission/absorption 等同样按本文学科取义，不默认天文。
   - 语境不足以判定时，忠实保留原文术语或按材料最直接的学科含义，不替它补一个天文解释。

2. 正式编号 / 命名 / 名目铭牌一律保留英文原文，中文备注用中文，不翻译不加中文扩写：
   - 模型/算法/数据集名（如 GPT-5.5、AlphaFold、ImageNet、PDB 等）与正式编号一字不改。
   - 机构/仪器/任务/项目官方英文名保留英文（如 OpenAI、DeepMind、CERN、LIGO、JWST 等）；天文专名若出现也按官方名保留。
   - 2–5 字母全大写缩写默认保留英文，按本文学科理解，不默认天文含义。
   - 单位/坐标/常量原样保留（如 eV、keV、Å、nm、K、σ、z、RA/Dec 等）。

3. 中国/华语机构与翻译习惯：遇到中文命名（如「悟空」「天宫」）可用中文，正式编号保留。

4. 代码 / 命令 / URL / 数字单位 / 坐标一字不改保留：
   - 反引号代码 `code` 不翻译；URL 原样。
   - 数字+单位（z=1.5 / 12,000 K / ×10⁻³ / 0.3 Mpc / 5 nm）原样；金额、比例、区间保留原文阿拉伯数字和单位，不改写成中文数量词。
