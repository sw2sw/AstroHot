## 1. 内容与版权

本平台展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有偏差或错误，重要信息请以原文及论文为准；因内容不准确造成的判断或决策影响，平台不承担责任。原文版权归各来源所有：站内只在来源允许时展示全文，其余仅展示摘要和原文链接。

本站用于天文学习与科普交流。配图按来源许可使用，完整署名及原始链接随图保留；仅允许教育或研究用途的图片按其条件使用并注明用途，版权不明或禁止转载的图片不予转载。“教育与研究用途”说明不替代版权许可。

## 2. 来源方的更正与下架

如果你是国家天文台、紫金山天文台、上海天文台、ESO、ESA、NOIRLab 等信源的版权方或来源方，希望更正、下架或调整某条内容的展示方式，请通过反馈页（footer 的“反馈”）联系，我们会在核实后尽快处理。

## 3. 使用本站的数据

- 允许的用途：个人阅读、学习与参考，组织内部研究使用，新闻写作中的引用（注明出处）。
- 需事先取得同意的用途：商业产品、公开转载、批量再分发、组建数据集用于模型训练等，请先与我们联系。
- 站内摘要为模型生成，引用时请以原文与论文为准。

## 4. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口，直接使用。请按响应中的缓存时间轮询；遇到 `429` 请遵守 `Retry-After`，不要并发重试，以免影响其他用户的稳定性。
